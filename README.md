# ChatHub - 网页聊天平台

一个轻量级、现代化的网页聊天平台，纯前端实现，无需后端。

## ✨ 功能特性

### 用户系统
- **注册**：用户名/昵称/密码，密码 SHA-256 哈希存储
- **登录**：会话持久化（刷新自动恢复）
- **登出**：一键退出，自动清理在线状态
- **表单验证**：用户名格式、密码长度、二次确认密码

### 聊天系统
- **公共聊天室**：所有人可见的群聊
- **私聊**：点对点私聊，独立会话
- **在线用户列表**：实时显示在线用户，心跳保活
- **实时消息**：基于 `BroadcastChannel` 跨标签页实时同步
- **消息历史**：localStorage 持久化，自动保留最近 200 条
- **正在输入提示**：私聊时显示对方输入状态
- **消息时间戳**：智能格式化（今天显示时分，其他显示日期）

### UI/UX
- 现代化暗色主题
- 渐变 + 毛玻璃效果
- 响应式布局，支持移动端
- 侧栏抽屉式（移动端）
- Toast 提示
- 平滑动画

## 🚀 部署到 GitHub Pages

1. 将此仓库推送到 GitHub
2. 进入仓库 Settings → Pages
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main`，文件夹选 `/ (root)`
5. 保存后等待 1-2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

## 🛠 技术栈

- 纯 HTML/CSS/JavaScript（无依赖、无构建）
- `BroadcastChannel API`：跨标签页实时通信
- `localStorage`：数据持久化
- `crypto.subtle`：密码 SHA-256 哈希

## 📱 使用说明

1. 打开网页
2. 点击「立即注册」创建账号
3. 注册成功后自动跳转登录页，登录
4. 进入聊天界面，默认打开公共聊天室
5. 切换到「在线用户」标签，点击其他用户开始私聊
6. 多开几个标签页（或窗口）注册不同账号，即可体验实时聊天

> **提示**：由于使用 `localStorage` 和 `BroadcastChannel`，聊天数据仅在当前浏览器内有效。不同浏览器或设备之间不共享数据。这是纯前端方案的特性，适合演示和轻量使用场景。
